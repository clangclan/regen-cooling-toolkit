# 6. 과도(시동·정지) 해석 방법론과 로드맵

이 장은 **방법론과 계획만** 다룹니다. 이 저장소에는 아직 과도 해석 코드가 없습니다. 정상 상태 1D 해석(2장)만으로
답할 수 없는 질문이 생겼을 때, 다음 단계 모델을 어떻게 짜면 되는지 정리했습니다.

## 6.1 왜 과도 해석이 필요한가

정상 해석은 "충분히 오래 탄 뒤"의 벽온도만 봅니다. 다음 질문에는 과도 해석이 필요합니다.

- **시동 순서.** 산화제와 연료 중 무엇을 먼저, 얼마나 일찍 여는가? 연료(냉각제)가 채널을 채우기 전에 연소가 시작되면
  벽이 얼마나 빨리 뜨거워지는가?
- **채널 안 끓음.** 시동 초기에는 채널 압력이 낮아 임계압 아래일 수 있습니다. 끓음 여유(2.9절)가 언제, 어디서 가장 작은가?
- **정지.** 연료를 먼저 잠그면 남은 연료가 뜨거운 벽에서 끓어 압력이 튀거나 열분해(coking)가 생길 수 있습니다.
- **짧은 연소.** 수 초 연소라면 벽이 정상 상태에 도달하지 않을 수 있습니다. 이때 정상 해석은 지나치게 보수적입니다.
- **공급계 결합.** 분사기·벤투리·조절 밸브가 채널 유량을 정하고, 채널의 압력강하와 출구 상태가 다시 분사기 유량을
  바꿉니다.

## 6.2 모델 구성 (권장)

### 벽: 2D 과도 열전도

- 축방향 x와 벽 단면을 함께 푸는 2D(또는 x를 따라 늘어선 단면들의 준3D) 과도 열전도입니다.
- 내벽, 리브, 덮개(jacket) 등 재료가 여럿이면 재료별로 ρ·c_p·k(T)를 둡니다.
- 축방향 전도는 2.8절과 같은 이유로 꼭 넣습니다. 시동 중에는 축방향 온도 기울기가 정상 상태보다 큽니다.
- 열용량이 큰 덮개와 플랜지는 별도 집중 절점으로 둘 수 있습니다.

### 냉각제: 에너지 저장 + 준정상 운동량

- 에너지식에는 채널 안 유체의 에너지 저장 항(∂(ρh)/∂t)을 넣습니다. 채널 체적이 작으면 체류 시간이 수십 ms 수준이라,
  시동 초기 몇백 ms 동안 무시하면 안 됩니다.
- 운동량은 준정상(관성 무시)으로 둡니다. 음속 전달 시간이 열 시간 척도보다 훨씬 짧기 때문입니다. 수격(water hammer)이나
  유동 진동을 보려면 별도 모델이 필요합니다.
- 상태량은 (P, h)로 들고 다닙니다. 유체가 액체 → 초임계 → 기체로 바뀌어도 하나의 식으로 다룰 수 있습니다.

### 실유체 물성 (넓은 압력 범위)

- 시동 중 채널 압력은 대기압 근처부터 정상 운전 압력까지 변합니다. 압력 하나에서 만든 물성표(2장)로는 부족합니다.
- 권장 구성:
  - 2D 물성표 (P, h) → T, ρ, μ, k, c_p를 만듭니다.
  - 아임계 액체 쪽은 액체 상관식, 포화선은 Lee–Kesler, 돔 안은 HEM 혼합으로 둡니다.
  - 초임계 쪽은 실유체 상태식 + 대응상태 수송물성을 씁니다.
  - 유사임계선 근처는 물성이 급변하므로 표 간격을 좁히고, 아임계/초임계 경계 근처(0.95–1.05 Pc)는 두 모델을 섞는
    완충 띠를 둡니다.
- 물성표 자체를 시험 자료나 기준 상태식(NIST REFPROP 등)과 비교해 오차 범위를 문서로 남깁니다.

### 열전달

- 난류 영역은 2장과 같은 상관식을 쓰되, 압력·온도가 넓게 변하므로 각 상관식의 적용 범위를 매 시간 단계에서 확인합니다.
- **유량이 작은 시동 초기에는 층류 발달 유동**이 됩니다. 1D Nusselt 상관식 대신 채널 반경 방향 2D 발달 유동을 풀고
  (Kirchhoff 변환으로 k(T) 처리), 벽 열유속을 반경 방향 적분으로 구하는 것이 안전합니다.
- 끓음은 처음에는 판정만 합니다 (2.9절과 같은 ONB/CHF 비율). 끓음 열전달 모델은 6.4절 로드맵에 있습니다.

### 공급계 결합

- 각 추진제 공급선에 오리피스(SPI / Dyer / HEM-PR, 5장), 공동화 벤투리, 밸브 개도 곡선을 둡니다.
- 경계조건 모드는 네 가지를 둡니다.
  - `fixed`: 유량을 고정합니다.
  - `venturi`: 벤투리가 막혀 있는 동안 유량이 상류 압력만으로 정해집니다.
  - `bc`: 시험 자료의 압력·유량 이력을 씁니다.
  - `dry`: 채널이 비어 있어 기체 정체 상태입니다.
- 채널 압력강하, 분사기 압력, 연소실 압력을 각 시간 단계의 반복 안에서 음해로 맞춥니다. 명시적으로 풀면 분사기 쪽
  강성 때문에 시간 간격이 매우 작아집니다.
- 연소실 압력은 c*와 유량의 준정상 관계로 둡니다 (연소실 충전 시간 상수는 필요하면 추가).

### 시간 적분

- 후진 Euler(1차, 음해)를 씁니다. 시동 과도는 매끄럽지 않은 사건(밸브 열림, 점화)이 많아 고차 기법의 이득이 작고,
  안정성이 더 중요합니다.
- 각 시간 단계에서 벽–냉각제–공급계를 외부 반복으로 맞추고, 수렴 이력을 남깁니다.

## 6.3 검증 절차

과도 해석 결과는 아래 확인을 거친 뒤에만 쓰세요.

1. **시간 간격 수렴.** Δt를 절반으로 줄여도 최대 벽온도와 그 시각이 거의 변하지 않아야 합니다 (예: < 1–2 K).
2. **격자 수렴.** 축방향, 단면 격자를 각각 다듬어 같은 기준으로 확인합니다.
3. **정상 상태 일치.** 충분히 긴 시간 뒤의 해가 정상 1D/2D 해석(2장, 3장)과 같아야 합니다.
4. **에너지 장부.** 매 시간 단계에서 다음을 기록하고, 합이 0에 가까운지 확인합니다.
   - 가스 → 벽 열량
   - 벽 저장 열량 변화
   - 벽 → 냉각제 열량
   - 냉각제 저장 열량 변화
   - 냉각제 엔탈피 유출입
5. **물성 경계 확인.** 해가 물성표 범위를 벗어나거나, 완충 띠 안에 오래 머무는 구간을 기록합니다.

## 6.4 아직 빠진 물리와 우선순위

| 항목 | 영향 | 권장 처리 |
|---|---|---|
| 끓음 열전달 (핵비등, 막비등) | 시동 초기 아임계 구간에서 벽온도가 크게 바뀜 | 먼저 판정만, 필요하면 Chen형 핵비등 + CHF 넘으면 막비등 |
| 근임계 열전달 악화 (HTD) | 유사임계점 근처 높은 열유속에서 Twg 급상승 | 판정 기준(q/G 비)으로 먼저 표시 |
| 유동 불안정 (밀도파, 압력강하 진동) | 아임계 끓음 구간의 유량 진동 | 선형 안정성 판정으로 먼저 확인 |
| 채널 간 유량 불균일 | 매니폴드 + 채널별 공차 (4장) | 과도 해석에서는 대표 채널 + 불균일 계수 |
| 원주방향 불균일 가열 | 혼합비 줄무늬, 분사기 패턴 | 섹터 모델 (6.5절) |
| 연소가스 복사 | 보통 대류의 몇 % (5장) | 5장 추정을 열유속에 더함 |
| 외벽 대류·복사 | 긴 연소, 정지 후 냉각 | 외벽 경계에 h_out과 방사율 |
| 연소실 점화 과도 | 가스 쪽 열유속의 시간 변화 | Pc(t)로 Bartz 스케일 |

우선순위는 다음과 같습니다.

1. 시간 간격·격자 수렴과 에너지 장부를 갖춘 기본 과도 해석
2. 넓은 압력 범위 물성표와 공급계 결합
3. 끓음·HTD 판정
4. 축소 모델 (6.5절)
5. 섹터 모델
6. 끓음 열전달

## 6.5 계산 비용 줄이기

- **축소 모델.** 벽을 x 방향 몇십 개 집중 절점(가스 쪽, 냉각제 쪽, 덮개)으로 줄이고, 절점 사이 열전도도를 정밀 2D 해에서
  보정합니다. 밸브 순서, 지연 시간 같은 파라미터 스윕은 축소 모델로 하고, 최종 후보만 정밀 해석으로 확인합니다.
  축소 모델과 정밀 해석의 최대 벽온도 차이를 대표 경우 몇 개로 기록해 두세요.
- **물성 캐시.** (P, h) 물성표를 한 번 만들어 파일로 저장하고 재사용합니다.
- **체크포인트.** 긴 과도 계산은 일정 간격으로 상태를 저장해 중간부터 다시 시작할 수 있게 합니다.
- **섹터 모델.** 원주방향 불균일이 중요하면 채널 하나 + 양옆 리브 반쪽의 섹터를 원주방향 여러 위치에서 독립적으로 풉니다.
  섹터 사이 전도는 무시하거나 보정 계수로 둡니다.
- **출력.** 시간 이력(최대 Twg와 위치, 끓음 판정, 공급계 압력·유량)은 CSV, 위치×시간 장은 압축 배열(npz/HDF5)로
  저장하고, 에너지 장부는 별도 파일로 남깁니다.

## 6.6 막냉각 사전 검토 방법

재생냉각만으로 벽온도 여유가 부족할 때 막냉각을 추가할지 판단하는 1차 방법입니다. 불확도가 매우 크므로
**설계값이 아니라 효과의 크기를 가늠하는 용도**입니다.

- **액막 냉각.**
  - 길이: Grissom 또는 Stechman 형태의 에너지 균형으로 액막이 증발해 사라지는 길이를 구합니다.
    가스 쪽 열유속이 액막 가열·증발에 쓰인다고 봅니다.
  - 안정성: 액막 표면파와 엔트레인먼트(entrainment) 손실을 보정 계수로 둡니다. 실제 손실은 시험으로만 알 수 있습니다.
- **기체막 냉각 (액막이 증발한 뒤, 또는 기체 분사).**
  - 효율: Goldstein형 단열 벽 효율 상관식을 쓰고, 혼합 계수(난류 혼합 강도)를 범위로 둡니다.
  - 가속 보정: 노즐 가속 구간에서 혼합이 줄어드는 효과는 Papell형 보정이나 가속 매개변수 적분으로 넣습니다.
- **결과 표현.** 혼합 계수와 손실 계수를 넓은 범위로 바꿔 최소–최대 띠로 보여 줍니다. 띠가 넓으면 그 자체가 결론이고,
  시험이나 CFD가 필요하다는 뜻입니다.
- **비용.** 막냉각 유량은 c* 손실로 이어집니다. 냉각 이득과 성능 손실을 함께 표로 비교하세요.
