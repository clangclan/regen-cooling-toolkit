# 4. 설계 연구: 최적화, 공차, 매니폴드

코드: `regencool/optimize.py`, `regencool/tolerance.py`, `regencool/manifold.py`

세 연구 모두 1D 해석([2장](2_regen_1d.md))을 여러 번 반복해서 돌립니다. 데모 엔진 기준으로 1D 한 번에
0.1–0.4초가 걸리고, 최적화(150회) 약 20초, 공차 약 7초, 매니폴드(응답표 7 × 10) 약 13초가 걸립니다.

## 4.1 채널 크기 분포 s(x) 최적화 (`optimize`)

**변수.** 몇 개의 축 위치(매듭)에서의 log s 값입니다. 매듭 사이는 PCHIP으로 이어 s(x)를 만듭니다.
매듭 위치는 `knots_x_mm`로 주고, 없으면 다음 6개를 씁니다.

    x0,  x0 + 0.4(x_t − x0),  x0 + 0.8(x_t − x0),  x_t,  x_t + 0.35(x_e − x_t),  x_e

**목적함수** (Nelder–Mead, 단위: °C와 bar):

    J = max Twg + 300 · max(0, ΔP − ΔP_max) + 300 · max(0, P_min − P_출구)

- 제약을 1 bar 넘길 때마다 300 °C의 벌점을 줍니다.
- 매듭 하나라도 `s_min_mm` (+ d) 아래면 큰 벌점을 더합니다.
- 채널이 막히거나 해석이 실패하면 J = 10⁴입니다.

**강건 최적화** (`robust_d_mm = d > 0`): 공차 ±d를 함께 봅니다.

    J = max( J_공칭,  max Twg(+d) ) + 300 · max(0, P_min − P_출구(−d))

- +d: 채널이 커지고 벽이 얇아집니다. 유속이 줄어 hc가 떨어집니다.
- −d: 채널이 작아져 ΔP가 커지고 출구 압력이 떨어집니다.

**시작점.** 현재 설정의 s(x)를 매듭에서 읽고, 균일 배율을 이분법으로 찾아 ΔP ≈ 0.85 ΔP_max가 되게 합니다.

**고정되는 것.** 벽 두께 t(x), 채널 개수, 나선각, 형상은 바뀌지 않습니다. web 최소 두께 제한(`web_min_mm`)은
최적화 중에도 적용됩니다.

**사용법.** 출력된 `s_mm = [...]` 줄(`optimized_s.toml`)을 설정 파일 `[channels]`에 붙여 넣고 `run`으로 확인합니다.

**주의.**

- Nelder–Mead는 국소 최적화입니다. 매듭 수나 위치, 시작점을 바꿔 결과가 비슷한지 확인하세요.
- 최적 s(x)가 제작 가능한지 따로 확인해야 합니다: 최소 형상 크기, 분말 제거, 표면 거칠기, 검사 가능성.
- 최적화는 1D 지표(최대 Twg, ΔP, 출구 압력)만 봅니다. 응력은 최적화 뒤 2D 단면 해석으로 확인합니다.

## 4.2 제작 공차 민감도 (`tolerance`)

**균일 오프셋 d** (모든 채널이 같이 커지거나 작아짐):

- 채널 형상 +d: rect는 폭과 높이, circ는 지름, tear는 전체 높이가 d만큼 커집니다.
- rect 리브는 −d.
- 고온벽은 −d/2 (채널 바닥이 d/2만큼 내려감).

`offsets_mm`의 각 d마다 1D 해석을 다시 합니다. 전체 ΔP, 출구 압력, 최대 Twg가 어떻게 변하는지 봅니다.

**채널 하나만 −d** (`one_channel_mm`): 가장 위험한 경우인 고온점(hot streak)을 봅니다.

- 작게 제작된 채널 하나는 공통 매니폴드 사이에서 다른 채널과 **같은 ΔP**를 받습니다.
- 그래서 dP(ṁ_f) = ΔP_공칭이 되는 유량 배율 ṁ_f를 이분법으로 찾고, 그 유량에서의 Twg를 구합니다.
- 채널 수가 많으면 하나가 줄어도 매니폴드 압력은 거의 그대로라는 가정입니다.

출력 `tolerance.csv`에는 경우마다 유량 배율, 최대 Twg와 위치, 노즐목 Twg, 냉각제 출구 온도, ΔP, 출구 압력,
최대 유속, 최소 s, 최소 web이 있습니다. `tolerance.png`는 공칭값을 점선으로 놓은 점 그림입니다.

## 4.3 입구 매니폴드와 유량 분배 (`manifold`)

입구 매니폴드는 노즐 출구 쪽 끝에 있는 링 헤더입니다. 입구 하나가 θ = 0에 있고, 두 갈래로 나뉘어
θ = 180°까지 갑니다 (좌우 대칭).

**헤더 정압 분포.** 각 갈래를 Δθ = 0.25° 간격으로 따라가며 정압 변화를 더합니다.

- 면적 변화에 의한 Bernoulli 항: −½ρ(u₂² − u₁²)
- Darcy 마찰: 층류 64/Re, 난류 Colebrook (헤더 수력직경 `dh_mm`, 거칠기는 냉각제와 같음)
- 채널 분기마다:
  - 분기 입구 손실: 채널 입구 정압 = 헤더 정압 − C_b · ½ρu_h²
  - 운동량 회복: 분기 뒤 헤더 정압 += k_r · ½ρ(u_h² − u_h′²)

헤더 단면적과 수력직경은 `theta_deg`, `area_mm2`, `dh_mm` 표를 선형 보간합니다. 대칭선(0°, 180°) 위에 있는
채널은 양쪽 갈래에서 절반씩 받습니다. 채널 각도는 채널 수와 랜드 배치(`n_land`, `land_deg`, `land0_deg`)로 정합니다.

결과는 채널마다 입구 정압 대비 오프셋 [bar]입니다. 첫 계산은 모든 채널 유량이 같다고 보고(균일 인출) 합니다.

**채널 응답표.** 채널 크기 오프셋 d(`d_grid_mm`)와 유량 배율 ṁ_f(`mf_grid`)의 격자에서 1D 해석을 모두 돌려,
ΔP, 출구 압력, 최대 Twg, 출구 온도, 포화 여유를 표로 만듭니다. 사이 값은 쌍선형 보간합니다.
해석이 실패한 격자점(막힘, 너무 작은 유량)은 보수적인 값으로 채웁니다.

**네트워크.** 모든 채널이 같은 출구 압력 P_o로 나간다고 봅니다.

- 채널 i의 유량은 dP_i(d_i, ṁ_f,i) = P_h + off_i − P_o를 만족해야 합니다.
- 채널 유량의 합이 전체 유량이 되도록 P_o를 이분법으로 찾습니다.

**Monte Carlo.** 채널마다 크기 오프셋을 정규분포 d_i ~ N(`mean_mm`, `sigma_mm`)로 독립적으로 뽑아
`samples`번 네트워크를 풉니다. 표본마다 최악의 채널 값을 모아 백분위로 요약합니다.

| 출력 | 의미 |
|---|---|
| `mf_min_p50`, `mf_min_p01` | 가장 적게 흐르는 채널의 유량 배율 (중앙값, 하위 1 %) |
| `Twg_max_p50`, `Twg_max_p99` | 가장 뜨거운 채널의 최대 Twg (중앙값, 상위 1 %) |
| `Pex_min_p01` | 최소 채널 출구 압력 (하위 1 %) |
| `psat_margin_p01` | 최소 포화 여유 (하위 1 %) |
| `Tout_max_p99`, `Po_p50` | 최대 채널 출구 온도, 출구 압력 |

**활용.**

- 공칭 결과의 유량 배율이 1에서 많이 벗어나면 헤더 단면적을 키우거나 입구 위치를 바꿉니다.
- `Twg_max_p99`가 재료 한계에 가까우면 제작 공차(σ)를 줄이거나 s(x)에 여유를 둡니다.
- σ는 실제 출력물을 CT나 단면으로 측정한 채널 크기 산포로 정하는 것이 좋습니다.

**한계.**

- 헤더는 1D 모델입니다. 분기 손실 C_b와 운동량 회복 k_r은 경험값이며, 입구 제트, 2차 유동, 분기 사이
  간섭 같은 3D 효과는 CFD로 확인해야 합니다.
- 채널 사이 열 전달(옆 채널과의 전도)이 없으므로, 고온점 채널의 Twg는 약간 보수적입니다.
- 채널 크기 산포는 채널마다 하나의 값(전 길이 균일)으로 봅니다. 위치에 따라 달라지는 산포는 표현하지 않습니다.
