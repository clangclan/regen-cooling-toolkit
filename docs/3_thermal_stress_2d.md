# 3. 2D 채널 단면 열-구조 해석

코드: `regencool/fe2d.py`, `regencool/station2d.py`

1D 해석 결과를 경계조건으로 써서, 지정한 축 위치 x에서 채널 한 개를 포함하는 원주 방향 섹터의
온도장과 응력장을 유한요소로 풉니다. `run` 명령이 `[stress] x_mm`의 각 위치에서 자동으로 실행합니다.

## 3.1 해석 영역

- x를 고정한 **횡단면 (r–θ 평면)**입니다.
- 섹터 각도는 2π / (N_eff · n_s)입니다. rect 채널이 n_s개로 나뉘어 있으면 하위 채널 하나를 해석합니다.
- 반경 방향 범위: 내벽 r_in → r_in + t + s + `jacket_mm`. 바깥 덮개(closeout) 두께가 `jacket_mm`입니다.
- 나선 채널을 횡단면으로 자르면 원주 방향으로 1/cos β만큼 늘어난 모양이 되므로, 채널 경계를 그렇게 늘려서 그립니다.

## 3.2 격자

- 극좌표 격자 위의 4절점 사각형(Q4) 요소, 2×2 Gauss 적분입니다.
- 반경 방향 요소 크기: 채널 꼭짓점 + 0.3 mm까지는 `h_mm`, 그 밖은 12 %씩 키워 최대 0.08 mm.
- 원주 방향 분할 수: max(8, r_in · Δθ / h).
- 채널은 **요소 중심이 채널 안에 있는 요소를 제거**하는 방식(픽셀 방식)으로 만듭니다. 그래서 채널 벽이
  계단 모양이 되고, 계단 모서리에 국부 응력 집중이 생깁니다 (3.5절).

## 3.3 열 해석

정상 열전도이고, 경계조건은 다음과 같습니다.

| 경계 | 조건 |
|---|---|
| 내벽 r = r_in | 대류: hg, Taw (1D 결과) |
| 채널 벽 | 대류: hc_eff, T_b (1D 결과) |
| 바깥면, 섹터 양옆 | 단열 |

**hc_eff.** 격자의 계단 모양 채널 벽은 실제 둘레보다 깁니다. 그래서 실제 둘레 기준의 열량이 같도록 hc를 바꿉니다.

    hc_eff = hc · (P_실제 / cos β) / P_격자

2D 격자가 핀(리브) 전도를 직접 풀기 때문에 1D의 핀 효율은 쓰지 않습니다.
그래서 2D의 최대 Twg는 1D 값과 조금 다릅니다. 둘 다 출력하니 비교하세요 (`Twg_max`, `Twg_1d`).

## 3.4 구조 해석

선형 탄성, **일반화 평면변형률**입니다.

- 축 변형률 ε_z는 단면 전체에서 같다고 보고, 축 방향 힘의 평형 ∫σ_zz dA = F_z에서 구합니다.
- 섹터 양옆에 u_θ = 0을 벌점법으로 줍니다 (주기 대칭). 반경 방향 팽창은 자유입니다.
- 압력 하중: 채널 벽에 냉각제 압력 P_c, 내벽에 가스 압력 p_g.
- 섹터 하나에 걸리는 축 방향 끝 하중:

      F_z = p_g · π r_in² / (N_eff · n_s) + P_c · A_ch / cos β

  해당 단면에서 내부가 막혀 있다고 볼 때의 가스 압력 추력과, 채널 끝단에 걸리는 냉각제 압력입니다.
  실제 엔진의 축 방향 구속(플랜지 볼트, 지지대)이 다르면 이 값이 달라집니다.
- 하중 경우 세 가지를 따로 출력합니다.

  | 이름 | 하중 |
  |---|---|
  | `th` | 열 하중만 (T − T_ref) |
  | `pr` | 압력 + 끝 하중만 |
  | `tot` | 둘을 합친 것 |

- 기준 온도 `T_ref_K`에서 응력이 0입니다.
- 검증: 채널 없이 온도를 고르게 올리면 응력 없이 팽창해야 합니다
  (`test_free_thermal_expansion_is_stress_free`: von Mises < 10⁻³ EαΔT, ε_z = αΔT).

## 3.5 결과 읽는 법

`summary.json`의 `stations`와 `station_x*.png` (온도, von Mises, 원주·축 응력 장)를 봅니다.

| 키 | 의미 |
|---|---|
| `Twg_max`, `Twg_min`, `Twg_1d` | 2D 내벽 최고·최저 온도, 1D 값 |
| `T_jacket`, `T_hotwall_mean` | 덮개, 고온벽의 면적 평균 온도 |
| `vm_max`, `vm_max_dr`, `vm_max_th_deg` | 최대 von Mises와 위치 (내벽에서의 거리, 각도) |
| `vm_max_off_channel` | 채널 벽에 닿은 요소를 뺀 최대 von Mises |
| `vm_hot_max` | 내벽 표면 요소의 최대 von Mises |
| `stt_mid`, `szz_mid`, `vm_mid` | 채널 중앙 아래 내벽의 원주·축·von Mises 응력 |
| `stt_web`, `szz_web`, `vm_web` | web(섹터 옆) 아래 내벽 값 |
| `stt_jacket`, `szz_jacket` | 덮개의 평균 응력 |
| `eps_z` | 축 변형률 |

- 고온벽은 차가운 덮개에 구속되어 **원주·축 방향 압축**이 됩니다. 크기는 대략 −EαΔT/(1 − ν)입니다
  (ΔT: 고온벽과 덮개의 평균 온도 차).
- `vm_max`가 채널 벽 계단 모서리에 있으면 격자 때문에 생긴 집중일 수 있습니다. `vm_max_off_channel`과 비교하고,
  `h_mm`을 반으로 줄여 값이 수렴하는지 확인하세요.
- 탄성 해석이므로 von Mises가 해당 온도의 항복강도를 넘으면 실제로는 소성이 생깁니다. 이 경우 매 시동마다
  소성 변형이 반복되므로, 저주기 피로나 래칫 평가를 따로 해야 합니다.

## 3.6 한계

- x를 고정한 횡단면입니다. 벽 기울기 |dr/dx| > 0.25 (수렴부, 확대부 일부)에서는 근사이며 경고를 냅니다.
  원통부와 노즐목 근처에서 쓰는 것이 좋습니다.
- 축 방향 열전도, 축 방향 온도 구배에 의한 굽힘, 시동·정지 과도 상태는 없습니다.
- 재료 물성(E, ν, α, k)은 온도에 무관한 상수입니다. 고온에서 E가 줄어드는 효과는 없습니다.
- 선형 탄성입니다. 소성, 크리프, 피로 수명은 계산하지 않습니다.
- 축 방향 끝 하중은 3.4절의 단순 가정입니다.
